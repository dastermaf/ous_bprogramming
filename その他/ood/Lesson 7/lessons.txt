class Payment {
public:
    virtual void pay() = 0;
};

class CashPayment : public Payment {
public:
    void pay() override {
        cout << "Pay by cash" << endl;
    }
};

class CardPayment : public Payment {
public:
    void pay() override {
        cout << "Pay by card" << endl;
    }
};

（Single Responsibility Principle、つまり単一責任の原則はなぜ必要ですか。）

神様のクラスが発生しないように、責任ずつに分ける必要がある。

探しづらい状況になってしまう。
